# ⚖️ Balança IMC

Projeto desenvolvido em **Java** com o objetivo de calcular o **Índice de Massa Corporal (IMC)** de uma pessoa e apresentar sua classificação de acordo com o resultado obtido.

O programa recebe informações do usuário, realiza o cálculo automaticamente e exibe os dados e a classificação final no terminal.

---

## 📋 Sobre o Projeto

A aplicação solicita ao usuário:

- Nome
- Gênero
- Peso
- Altura

Após receber essas informações, o sistema calcula o IMC utilizando a fórmula:
